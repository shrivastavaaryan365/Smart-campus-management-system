# Smart Campus Management System

A responsive, browser-based campus dashboard prototype for bringing common student and campus services into one interface. It is built with plain HTML, CSS, and JavaScript.

## Features

- Demo login with Student, Faculty, and Administrator role selection
- Dashboard with campus activity summaries
- Attendance, assignments, timetable, notices, and results sections
- Leave application, complaints, and profile sections
- Dark mode and responsive navigation
- Browser `localStorage` for demo login state and preferences

## Getting Started

### Requirements

A modern web browser. No package installation or build step is required.

### Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/shrivastavaaryan365/Smart-campus-management-system.git

   2. Open the project folder.
3. Open index.html in your browser.
For a local development server, you can use the VS Code Live Server extension or run:

python -m http.server 8000

Then visit http://localhost:8000.
Demo Login
Enter any email address and password, then choose a role. The login is for demonstration only and does not authenticate users against a server.

Limitations
This is a front-end prototype. It does not include a backend, database, real authentication, or server-side role permissions. Dashboard figures and campus data are sample content. Do not use real credentials or sensitive personal information.
